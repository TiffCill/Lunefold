# Markdown、素材操作与时间线交互设计

日期：2026-08-25

## 目标

完善 AI 媒体编辑器的三个核心工作流：让对话回复可读、让素材能从素材库直接进入会话或时间线、让时间线移动与缩放稳定且具有专业编辑器应有的吸附反馈。

本次范围包括：

- 助手回复支持安全的 Markdown 渲染。
- 素材右键菜单支持添加到会话、添加到时间线、在 Finder 中显示源文件。
- 会话支持多个素材引用。
- 时间线片段移动支持双边缘吸附和视觉辅助线。
- 时间线默认充满可视区域，缩放后正确扩展并可横向滚动，不再因滚动反馈导致无限扩张或崩溃。
- 本地 companion 接管素材目录选择、扫描、安全访问和 Finder 定位。

不在本次范围内：

- 重构整体界面。
- 自动把 AI 生成结果加入时间线。
- 波形、代理文件、缩略图缓存等深层媒体处理。
- Windows/Linux 原生文件管理器适配；接口保留扩展能力，本次实现 macOS Finder。

## 设计原则

- 对话、素材和时间线使用明确的数据接口，避免组件间隐式共享状态。
- 所有本地路径只存在于 companion，浏览器仅使用不透明素材 ID。
- 时间线像素与时间的换算由纯函数完成，拖动预览与最终领域命令采用同一套结果。
- 吸附阈值按屏幕像素定义，缩放后手感不变。
- 菜单和辅助线反馈即时、克制、可中断，并支持键盘和减少动态效果偏好。

## 1. Markdown 对话展示

助手消息使用 `react-markdown` 和 `remark-gfm` 渲染。支持标题、段落、强调、列表、引用、链接、表格、任务列表、行内代码和代码块。

安全边界：

- 不启用 `rehype-raw`，模型返回的原始 HTML 作为普通文本处理。
- 链接协议只允许 `http`、`https` 和 `mailto`；其他协议不生成可点击链接。
- 外部链接使用安全的 `rel="noreferrer noopener"`。
- 用户消息始终以纯文本渲染。
- 工具调用或内部控制块不得作为普通 Markdown 展示。

消息模型从两组字符串升级为统一消息数组：

```ts
interface ConversationMessage {
  id: string;
  role: 'user' | 'assistant' | 'status';
  content: string;
}
```

渲染组件独立为 `MarkdownMessage`，便于单独测试危险 HTML、链接、表格和代码块。

## 2. 素材目录与本地 companion

### 2.1 目录所有权

现有浏览器 `FileSystemDirectoryHandle` 无法提供 macOS 绝对路径，因此无法实现 Finder 定位。本次将目录选择与扫描迁移到 companion。

流程：

1. 用户点击“选择素材目录”。
2. 浏览器请求 `POST /api/media-library/select-directory`。
3. companion 打开 macOS 原生目录选择器。
4. 用户选择后，companion 保存根目录路径到本地私有设置。
5. companion 递归扫描支持的视频、图片和音频文件。
6. 浏览器通过 `GET /api/media-library` 获得素材元数据。
7. 素材内容通过 `/api/media/:mediaId/content` 读取，浏览器不接触绝对路径。

目录选择属于用户主动触发的本地操作；取消选择不会覆盖原有目录。

### 2.2 素材标识与安全

companion 为每个文件生成稳定、不透明的 `mediaId`，内部映射包含规范化绝对路径、相对路径、大小和修改时间。

所有读取和 Finder 操作必须：

- 根据 `mediaId` 查询服务端索引，禁止前端提交系统路径。
- 对真实路径执行规范化与根目录包含检查。
- 拒绝符号链接逃逸、`..` 穿越和未收录文件。
- 文件消失时返回明确的 `media_not_found`。
- 根目录不可访问时返回 `directory_unavailable`，不泄露完整系统路径。

### 2.3 Finder 定位

`POST /api/media/:mediaId/reveal` 在验证后使用 macOS `open -R -- <absolutePath>` 显示并选中文件。命令以参数数组执行，不经过 shell 字符串拼接。

## 3. 素材右键菜单

素材方块监听 `contextmenu`。打开菜单时同时选中该素材，并将菜单锚定在指针位置。菜单根据视口边缘自动翻转或位移。

菜单项：

1. 添加到会话
2. 添加到时间线
3. 在 Finder 中显示

交互规则：

- 点击菜单外、按 Escape、窗口失焦或开始滚动时关闭。
- 支持方向键移动、Enter 执行、Escape 关闭。
- 菜单出现与消失使用短距离缩放和透明度变化，变换原点对应右键位置。
- `prefers-reduced-motion` 下只使用短透明度过渡。
- 演示素材没有真实源文件时，“在 Finder 中显示”禁用并说明原因。

## 4. 添加到会话

App 维护 `conversationReferences: string[]`，保存素材 ID 而不是素材对象。重复添加同一素材不产生重复项。

输入框上方以可移除引用标签展示多个素材。发送消息时创建本轮引用快照；发送完成后默认保留引用，方便连续讨论，用户可手动移除。

传输规则：

- 图片按 GPTBots 图片内容传输。
- 音频仅在对话 API 和 Agent 能力支持时传输，否则在发送前提示不支持。
- 视频作为 Seedance 工具参考素材使用；若 GPTBots 对话接口不能直接接收视频，则 companion 提供受控素材读取或 Modellix 可访问的上传结果，不伪装成图片。
- 最终工具调用只能使用本轮仍处于引用列表中的素材 ID。

## 5. 添加到时间线

右键“添加到时间线”从当前播放头插入：

- 图片默认时长 5 秒。
- 视频与音频使用源文件时长，无法读取时使用 5 秒并显示提示。
- 优先使用当前选中片段所在的兼容轨道；否则使用排序最靠前的兼容轨道。
- 没有兼容轨道时自动创建轨道，再插入素材。
- 如果播放头位置重叠，从播放头开始查找该轨道后方最近的空隙。
- 插入后选中新片段，但不自动开始播放。

“查找最近空隙”由时间线领域纯函数完成，右键插入和拖放插入共同使用，避免两种入口产生不同结果。

## 6. 时间线吸附

### 6.1 吸附计算

移动片段时，移动片段的开始和结束边缘分别与其他片段的开始和结束边缘比较。候选目标可来自所有轨道，以支持跨轨道对齐。

对每个候选计算所需的时间偏移，再换算为屏幕像素。选择绝对像素距离最小且不超过 8px 的候选。如果距离相同，优先保持当前轨道内的吸附目标，再按目标时间排序，保证结果稳定。

移动后的位置不得小于 0。吸附结果仍需通过领域层的轨道类型和重叠检查。

缩放片段起点或终点沿用单边缘吸附。

### 6.2 视觉反馈

发生吸附时，在对应时间位置显示贯穿可见轨道区域的辅助线。辅助线不拦截指针事件，并在脱离阈值、取消手势或提交手势后立即消失。

拖动中的片段直接显示吸附后的预览位置，而不是松手时突然跳动。手势保持 Pointer Capture，可在拖出片段边界后继续操作。

## 7. 时间线宽度与缩放

### 7.1 根因

现有内容时长使用 `max(duration, scrollTime + 10)`。横向滚动会增加内容宽度，增加后的宽度又允许继续滚动，形成自我扩张。缩放时该反馈会进一步放大，并生成越来越多的标尺节点。

### 7.2 新的视口模型

使用 `ResizeObserver` 获取时间线滚动容器的可视宽度：

```ts
interface TimelineViewportState {
  pixelsPerSecond: number;
  scrollTime: number;
  viewportWidth: number;
}
```

内容宽度只由以下因素决定：

```ts
contentWidth = max(
  viewportWidth,
  labelWidth + projectDuration * pixelsPerSecond + endPadding
)
```

滚动位置不得影响 `projectDuration` 或 `contentWidth`。

### 7.3 缩放行为

- 缩放范围保持 12–160 px/s。
- 以当前播放头为视觉锚点；播放头不在可视区时以视口中心时间为锚点。
- 更新缩放后重新计算并限制 `scrollLeft` 到 `[0, contentWidth - viewportWidth]`。
- 缩小时内容至少填满整个可视宽度。
- 放大时内容宽度实际增长，出现原生横向滚动，而不是压缩片段。
- 时间线末尾的固定余量只影响工作区，不计入项目或预览时长。

### 7.4 标尺虚拟化

标尺刻度只渲染当前可视时间范围前后一个步长。刻度步长继续依据缩放级别选择，但不再根据完整内容宽度创建无限数组。

## 8. 错误处理

- Finder 操作失败：在素材库显示非阻塞错误提示，不关闭菜单前已完成的选择状态。
- 目录权限失效：素材库显示恢复目录入口。
- 添加时间线失败：展示具体原因，如轨道锁定、类型不匹配或找不到空隙。
- Markdown 渲染异常：退回纯文本消息，不使整个助手面板崩溃。
- 时间线 ResizeObserver 不可用：使用容器首次测量和窗口 resize 作为回退。

## 9. 测试策略

### 单元测试

- Markdown 禁止原始 HTML，并正确渲染 GFM。
- 素材路径必须位于授权根目录，拒绝路径穿越和符号链接逃逸。
- Finder reveal 只接收已索引 mediaId。
- 双边缘吸附选择最近目标，阈值随缩放保持 8px。
- 最近空隙查找覆盖播放头冲突、多片段间隙和无可用轨道。
- 内容宽度不依赖 scrollTime。
- 缩放保持锚点并限制滚动范围。
- 可见刻度范围数量有界。

### 组件测试

- 右键菜单打开、键盘操作、关闭和禁用状态。
- 多素材添加与移除会话引用。
- 右键加入时间线使用播放头和兼容轨道。
- 拖动吸附时片段与辅助线同步更新。
- 时间线容器变宽时仍充满页面，放大后可横向滚动。

### 集成验收

- 选择真实本地目录后可展示素材并在 Finder 定位源文件。
- 添加多个素材到会话后发送，引用快照与当前 UI 一致。
- 在不同缩放级别移动片段，吸附距离体感一致。
- 反复放大、缩小和滚动不导致宽度无限增长、页面崩溃或预览时长改变。
