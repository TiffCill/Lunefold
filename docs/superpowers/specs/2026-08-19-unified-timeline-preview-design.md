# 统一时间轴与节目预览设计规格

日期：2026-08-19

## 目标

重做时间轴与预览之间的数据和交互边界。时间轴项目数据是节目预览、标尺、播放头、项目时长和后续导出的唯一事实来源；界面不得维护第二套片段位置、片段宽度或节目时间。

首阶段交付水平缩放、滚动、素材拖入、片段移动、同类型跨轨道移动、左右边缘调整、同轨冲突检测、边缘吸附、视觉层级解析、黑屏间隔、视频末帧保持以及完整撤销/重做。

## 非目标

首阶段不实现视频内嵌音频自动拆分、轨道整体排序、同轨转场重叠、波纹编辑、循环延长、关键帧、透明度与混合模式、代理文件和最终编码导出。

## 统一素材模型

素材记录描述源文件，不保存时间线位置：

```ts
type MediaKind = 'video' | 'image' | 'audio';

interface MediaAsset {
  id: string;
  name: string;
  kind: MediaKind;
  src: string;
  sourceDuration: number | null;
  availability: 'online' | 'offline';
}
```

视频和音频在导入后解析 `sourceDuration`。图片的 `sourceDuration` 为 `null`。无法解析时使用默认时间线长度：视频 5 秒、图片 5 秒；音频必须解析出时长后才可提交到时间轴。

视频素材拖入时间轴时只创建视觉片段，不自动拆出或创建音频片段。独立音频文件只能进入音频轨道。

## 统一时间线模型

```ts
interface TimelineClip {
  id: string;
  assetId: string;
  trackId: string;
  start: number;
  duration: number;
  sourceIn: number;
}

interface TimelineViewport {
  pixelsPerSecond: number;
  scrollTime: number;
}
```

- `start` 是片段在项目时间线中的开始时间。
- `duration` 是片段在时间线中占用的时间。
- `sourceIn` 是片段读取源素材的起点。
- 所有时间使用秒作为领域单位，允许小数。
- 项目时长为所有片段 `start + duration` 的最大值，包括音频片段。
- 像素位置只通过 `x = (time - scrollTime) × pixelsPerSecond` 计算。
- 时间轴组件不得把 CSS `transform`、元素宽度或拖动偏移当作已提交项目状态。

图片可以任意延长。视频可以超过 `sourceDuration - sourceIn`，超出部分保持最后一帧。音频超过源时长的部分保持静音，不循环。

## 命令边界

所有项目修改通过可撤销命令提交：

- `insertClip`
- `moveClip`
- `moveClipToTrack`
- `resizeClipStart`
- `resizeClipEnd`
- `deleteClip`
- `addTrack`
- `deleteTrack`

命令负责类型校验、同轨冲突检测、吸附结果校验和历史记录。组件只维护一次交互期间的临时手势状态；松手前不得修改项目快照。

## 轨道和层级

- 视觉轨道接受视频和图片。
- 音频轨道只接受音频。
- 同一轨道禁止片段时间区间重叠。
- 不同视觉轨道允许在相同时间存在片段。
- 视觉轨道越靠上层级越高。
- 片段可上下拖动到其他同类型轨道。
- 首阶段不支持轨道整体重排。

同轨冲突使用半开区间判断：两个片段在 `[start, start + duration)` 上相交即为冲突；首尾相接不冲突。

## 时间轴视口和缩放

项目时长与视口是不同概念。改变项目时长不自动改变 `pixelsPerSecond`。

- 缩放以播放头为中心，缩放前后播放头的屏幕横坐标保持不变。
- 标尺刻度根据 `pixelsPerSecond` 动态选择帧、1 秒、5 秒、10 秒或更大间隔。
- 时间轴内容超出可视宽度时横向滚动。
- “适合项目宽度”按钮可显式调整缩放，使完整项目进入可视区域。
- 缩放和滚动不进入项目撤销历史。
- 标尺、播放头、片段位置和片段宽度必须使用相同视口换算函数。

## 素材拖入

- 素材库条目提供素材 ID 和类型的拖动载荷。
- 视觉轨道拒绝音频；音频轨道拒绝图片和视频。
- 拖动期间显示按真实时间长度计算的半透明占位片段。
- 接近播放头或其他片段边缘时吸附。
- 吸附阈值为 8 屏幕像素，因此不随缩放级别改变手感。
- 同轨重叠或轨道类型错误时显示无效占位，松手不提交。
- 合法松手通过 `insertClip` 创建片段并进入撤销历史。

## 片段移动和边缘调整

- 拖动片段主体改变 `start`。
- 上下拖动可改变 `trackId`，目标必须是同类型轨道。
- 同轨禁止重叠，合法位置可吸附到播放头和片段边缘。
- 左边缘向右移动时增加 `sourceIn`、减少 `duration`，但不改变片段结束时间。
- 左边缘向左扩展不得导致 `sourceIn < 0`。
- 右边缘修改 `duration`，图片可任意延长；视频允许超过源剩余时长。
- 音频允许延长，但超过源素材的部分为静音。
- 片段最短时长为一帧；项目帧率首阶段固定为 24 fps。
- 按下时立即反馈，拖动全程 1:1 跟随指针，松开时提交一次命令。
- `Escape` 取消手势并恢复原状态。

## 节目解析

预览只消费时间轴解析结果：

```ts
interface ProgramState {
  time: number;
  duration: number;
  visual: ProgramVisual | null;
  audio: ProgramAudio[];
}
```

解析规则：

1. 活动片段满足 `start <= time < start + duration`。
2. 视觉候选来自所有视觉轨道的活动视频或图片片段。
3. 选择最高视觉轨道的活动片段。
4. 高轨道为空时显示下一条低轨道的活动片段。
5. 所有视觉轨道为空时显示黑屏。
6. 音频结果包含所有未静音音频轨道上的活动音频片段。
7. `sourceTime = sourceIn + time - start`。

片段间隔只有在所有视觉轨道都没有活动片段时才产生黑屏。高轨道片段之间的空档会露出低轨道内容，这与最终合成层级一致。

## 预览控制

- 项目播放头是唯一主时钟。
- 素材库选择不得改变节目预览。
- 切换到另一个活动片段时才更换预览媒体源。
- 同一视频片段内移动播放头只更新该媒体元素的 `currentTime`。
- 视频目标时间限制为 `min(sourceTime, sourceDuration - 1 / fps)`；超过源时长时保持最后一个可解码帧。
- 图片在整个片段时间内保持静态。
- 拖动播放头时暂停媒体播放，松手后根据拖动前状态决定是否继续播放。
- 视觉片段结束但项目仍有音频时，项目继续播放并显示黑屏。
- 视频元素不得通过自身 `timeupdate` 反向覆盖项目播放头。

## 状态和错误

- 素材离线时保留片段位置和时长，预览显示“素材离线”。
- 视频目标帧尚未解码时保留上一张完成画面并显示轻量加载状态。
- 错误轨道、同轨冲突和非法左边缘扩展显示无效状态，松手后不提交。
- 删除包含片段的轨道需要确认。
- 删除、移动、跨轨道移动、插入和边缘调整均支持撤销/重做。

## Apple Design 交互约束

Apple Design 规则只应用于本次重做的时间轴手势和预览反馈，不重构其他模块。

- 指针按下立即反馈。
- 拖动期间片段和指针保持 1:1，不使用延迟动画。
- 无效位置使用连续阻力和明确颜色反馈，不突然跳回。
- 松手后只对吸附或回退使用临界阻尼，无装饰性弹跳。
- 动画可中断；新的拖动从当前屏幕位置开始。
- 减少动态效果时取消吸附动画，但保留状态和颜色反馈。
- 键盘焦点、高对比度和减少透明度状态必须可用。

## 测试策略

领域测试：

- 项目时间与源时间换算。
- 项目时长包含视觉和音频片段。
- 最高视觉轨道覆盖低轨道。
- 高轨道空档显示低轨道。
- 所有视觉轨道空档返回黑屏。
- 视频超过源时长后钳制到最后一帧。
- 同轨重叠被拒绝，首尾相接被允许。
- 吸附结果在不同缩放级别下保持相同像素阈值。

命令测试：

- 插入、水平移动、同类型跨轨道移动。
- 左右边缘调整。
- 错误轨道和冲突不改变状态。
- 每次松手只创建一条历史记录。
- 撤销和重做恢复完整片段状态。

组件测试：

- 素材拖入正确轨道。
- 缩放以播放头为中心。
- 标尺、片段和播放头使用同一坐标换算。
- 横向滚动不改变项目时间。
- 无效拖放和 `Escape` 取消。

集成测试：

- 在同一时间点，时间轴命中片段、显示层级和预览素材一致。
- 移动或调整片段后预览立即使用新项目数据。
- 图片延长、视频末帧保持和音频延长黑屏行为一致。
- 素材库选择不影响预览。

## 完成标准

- 时间轴项目数据是预览、项目时长和标尺的唯一事实来源。
- 支持水平缩放、横向滚动和“适合项目宽度”。
- 支持素材库拖入对应类型轨道。
- 支持片段水平移动和同类型跨轨道移动。
- 支持左右边缘调整时长。
- 同轨禁止重叠并支持边缘吸附。
- 视觉层级、空档黑屏和低轨道透出规则正确。
- 图片自由延长、视频末帧保持、音频超长静音规则正确。
- 不再以 CSS 临时位移作为最终片段位置。
- 所有自动化测试通过，并完成浏览器手动验收。
