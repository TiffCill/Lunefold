# 时间线驱动预览与平级素材库设计规格

日期：2026-08-18

## 目标

纠正当前原型中素材、预览和时间线相互独立的问题。节目预览必须完全由时间线在当前播放头位置的内容决定；本地素材库采用平级文件模型，不再推断或维护版本堆栈。

## 范围

本阶段实现：

- 素材库从纵向卡片和版本堆栈改为平级正方形宫格。
- 每个本地文件或 AI 生成结果都是独立素材。
- 时间线片段直接引用一个具体素材 ID。
- 预览器只显示时间线在播放头位置的节目内容。
- 多条视觉轨道重叠时，最高可见轨道完全覆盖下方轨道。
- 空白时间显示黑屏。
- 失效文件显示“素材离线”。
- 内置演示媒体作为普通素材预先放入时间线，不再作为独立于时间线的预览源。

本阶段不实现透明度、空间变换、混合模式、真实多轨音频混音、完整素材拖放或源监视器。音频重叠时解析出活动音频集合并显示状态，为后续音频引擎提供接口。

## 平级素材模型

删除 `AssetStack`、`AssetVersion`、`currentVersionId`、`versionIds` 以及素材版本替换命令。统一素材记录为：

```ts
type MediaKind = 'video' | 'image' | 'audio';

interface MediaAsset {
  id: string;
  name: string;
  kind: MediaKind;
  source: 'demo' | 'local' | 'generated';
  objectUrl: string;
  size: number;
  modifiedAt: number;
  duration?: number;
  width?: number;
  height?: number;
  availability: 'online' | 'offline';
}
```

本地目录中的每个文件对应一条记录。AI 生成新结果时创建新的素材 ID 和新宫格方块，不与已有文件建立隐含版本关系，不解析用户目录层级或命名规则。

素材 ID 对于同一个本地文件仍由相对路径、大小和修改时间构成。文件内容或修改时间变化后视为新素材；旧时间线引用无法解析时进入离线状态，不自动重定向。

## 素材库宫格

素材库以无表头的正方形宫格展示。每个视频、图片或音频素材占一个 1:1 方块，按从左到右、从上到下排列。缩略图填满方块，文件名通过底部渐变遮罩叠放，类型徽标位于右上角；音频没有画面时使用统一音频图形占位。

交互规则：

- 单击选择方块，只改变素材库选择状态，不改变节目预览。
- 双击或空格打开素材快速查看属于后续“源监视器”能力，本阶段不实现。
- 不显示表头；宫格区域独立纵向滚动，不产生横向滚动。
- 目录状态和“选择素材目录”保留在宫格上方工具栏。
- 版本堆栈、优化按钮、当前版本和“时间线仍使用某版本”的文案全部删除。

### 模块内自适应

素材宫格响应素材库模块自身的实时宽度，不使用页面级媒体查询，也不要求重构其他模块：

- 使用 `grid-template-columns: repeat(auto-fill, minmax(96px, 1fr))`，模块变宽时自动增加列数，变窄时自动减少列数。
- 每个素材方块固定 `aspect-ratio: 1 / 1`，视频、图片和音频采用完全一致的几何尺寸。
- 模块宽度低于 192px 时保持单列，不横向滚动，也不退化为纵向详情列表。
- 方块间距为 8px，内边距以约 10px 为基准并允许用 `clamp()` 小幅自适应。
- 模块高度只决定当前可见的行数；素材顺序、方块尺寸规则和选择状态不因高度变化而改变。

视觉文件名可省略，但完整文件名始终通过 `title` 和无障碍名称可读。类型、离线状态等关键信息通过角标表达，不增加表头或额外数据列。

## Apple Design 适用边界

Apple Design 规则只应用于本次新增或发生行为变化的界面：素材宫格、时间线驱动预览切换，以及这些功能直接依赖的反馈。标题栏、创作助手、既有时间线外观和其他未修改模块不做整体视觉重构。

- 方块按下即反馈，松开后提交选择；选择反馈克制，不使用弹跳或宫格重排动画。
- 宫格沿用现有素材模块材质，不叠加新的半透明层级。
- 预览源切换使用短交叉淡化；减少动态效果时静态切换。
- 既有可拖动分隔条继续保持 1:1 跟手、可中断、软边界和临界阻尼回正。
- 新增样式必须提供减少透明度、高对比度和键盘焦点状态。

## 时间线片段模型

时间线片段简化为对具体素材的引用：

```ts
interface TimelineClip {
  id: string;
  assetId: string;
  trackId: string;
  start: number;
  duration: number;
  sourceIn: number;
}
```

`sourceIn` 表示片段从原素材的哪个时间开始。图片的源时间固定为零。片段不保存“最新版本”或版本 ID；引用的素材不可用时片段保持原位置和时长并显示离线状态。

删除旧的片段版本下拉框。片段选择、轨道增删和撤销/重做继续保留。

## 节目预览解析

新增纯函数解析当前节目状态：

```ts
interface ProgramFrame {
  visual: {
    clipId: string;
    asset: MediaAsset;
    sourceTime: number;
  } | null;
  audio: Array<{
    clipId: string;
    asset: MediaAsset;
    sourceTime: number;
  }>;
}

resolveProgramFrame(state, playheadTime): ProgramFrame
```

解析规则：

1. 活动片段满足 `start <= playheadTime < start + duration`。
2. 视觉候选仅来自未隐藏的视频轨道，素材类型可以是视频或图片。
3. 视觉候选按轨道显示顺序选择最高轨道；最高轨道完全覆盖下方轨道。
4. 音频集合包含未静音音频轨道上的全部活动音频素材。
5. `sourceTime = sourceIn + playheadTime - clip.start`；图片固定为零。
6. 没有视觉候选时 `visual` 为 `null`，预览显示黑屏。
7. 素材离线时保留候选位置，但预览显示“素材离线”，不得回退到演示视频或其他素材。

轨道新增 `hidden` 字段用于视觉可见性；现有 `muted` 控制音频是否进入活动集合。

## 播放控制

播放头是节目时间的唯一事实来源。预览不再拥有独立的固定演示媒体时间：

- 播放时，节目时钟推进播放头。
- 当前视觉片段是视频时，将媒体元素定位到解析出的 `sourceTime`。
- 当前视觉片段是图片时保持静态画面，节目时钟继续推进。
- 视觉片段切换时替换媒体源并定位到新的 `sourceTime`。
- 空白区保持黑屏，节目时钟继续推进。
- 暂停、定位和逐帧都先更新播放头，再重新解析节目画面。
- 节目时长取所有时间线片段结束时间的最大值；无片段时为零。

为了避免原生视频时钟与节目时钟相互争夺，节目控制器是主时钟，媒体元素是被同步的渲染器。首版允许小范围定位误差；当视频媒体与节目时间偏差超过 100ms 时重新定位。

## 演示数据迁移

内置演示视频成为 `source: 'demo'` 的普通 `MediaAsset`，并创建一个位于 V1、从 0 秒开始的时间线片段。其他演示图片和音频可继续作为普通素材方块，但只有已放入时间线的内容会进入节目预览。

原有基于版本的演示片段迁移为直接素材引用。删除所有版本标签和版本选择控件。

## 本地目录生命周期

目录扫描结果进入统一 `MediaAsset` 表。重新扫描时：

- 仍存在且稳定 ID 相同的素材保持时间线引用。
- 已消失的素材记录保留为 `offline`，供时间线和项目状态引用。
- 新文件追加为新素材方块。
- object URL 更换时更新在线素材的 URL，并释放不再使用的旧 URL。

当前浏览器原型不持久化完整项目；刷新后只恢复目录句柄并重建素材表和演示时间线。项目保存将在后续阶段实现。

## 状态与错误

- 空目录：宫格显示空状态，但演示素材仍作为普通 `demo` 方块存在。
- 不支持文件：计入忽略数量，不生成素材方块。
- 解码失败：素材保持在线，宫格显示通用缩略图；进入节目时预览显示解码错误。
- 文件消失：素材标记离线，时间线不自动删除片段。
- 播放头落在空白区：正常黑屏，不视为错误。

## 测试策略

领域测试：

- 平级素材不包含版本字段。
- 时间线片段只引用具体 `assetId`。
- 节目解析在边界时间正确激活和结束片段。
- 高视觉轨道覆盖低轨道。
- 隐藏轨道不进入视觉结果。
- 静音音频轨道不进入活动音频集合。
- 空白时间返回空视觉。
- 删除轨道或片段后节目结果立即变化。
- 离线素材保持时间线引用。

组件测试：

- 素材库使用宫格语义、无表头，并以正方形方块自动换列。
- 选择素材方块不改变节目预览。
- 不存在版本堆栈、版本按钮和片段版本下拉框。
- 播放头跨越片段边界时切换视觉素材。
- 空白时间显示黑屏。
- 离线素材显示明确状态。
- 视频、图片和音频方块均可展示且尺寸一致。

回归测试：

- 三栏和时间线尺寸仍可调整并保存。
- 视频轨道与音频轨道仍可添加、删除和撤销。
- AI 模型选择仍可撤销/重做同步。
- 本地目录授权、恢复和三类文件识别不回退。

## 完成标准

- 用户无法通过仅选择素材库文件改变节目预览。
- 预览内容始终可追溯到播放头位置的一个时间线视觉片段，或明确黑屏/离线状态。
- 素材库中每个文件和每个 AI 生成结果都以独立正方形方块展示。
- 界面和领域模型中不存在版本堆栈、版本 ID 或“最新版本”概念。
- 视觉轨道覆盖和活动音频解析规则通过自动化测试。
- 既有布局、轨道管理、本地目录和模型选择行为保持可用。
